# Contribution policy

YACP is a personal firmware project.

GitHub Issues are open for reproducible bug reports, hardware feedback, and focused technical discussion. Please include
the YACP version, device model, steps to reproduce, and any useful photos or logs.

Pull requests are not accepted at this time and are closed automatically. Opening an issue does not guarantee that a
feature request or support request will be implemented.

The source remains public for inspection and forking. If you need a different direction, maintain it in your own fork.
